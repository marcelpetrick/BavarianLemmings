# Level reference: the original level list (plan M6.01)

> Living document. Last update: 2026-10-11.
> Purpose: the puzzle facts of the 120 original levels, so that our own recreations
> (`assets/levels/<rating>/`) keep the original's progression (vision L-01, L-01a).

## How this table was made

1. Only public **text** descriptions were read: level name lists and walkthroughs (vision X-05).
2. No original level file, graphic or data file was downloaded or opened (vision X-02).
3. Every value carries its source in the "Src" column. The sources are listed at the end.
4. A value that no source confirms for the DOS version is marked `[verify]`.
5. The "key idea" column is our own one-line summary of the puzzle, not a quote.

Terms used in the tables:

- **Lemmings**: how many lemmings leave the hatch.
- **Save**: the rescue target in percent of the lemmings.
- **RR**: the release rate at the start (the minimum; the player can only raise it).
- **Time**: the time limit in minutes.
- **Skills**: the skills that the known solutions use. The counts per skill are not in the text
  sources and are therefore `[verify]` throughout; our levels set their own counts.

Known differences between the sources:

- Source G describes the Mega Drive / Genesis version. Its level order matches the DOS order for
  most Fun levels, but a few slots hold different levels there (marked "G differs"). The Mega Drive
  allows 100 lemmings; the DOS version allows at most 80 (vision G-15). Counts above 80 are
  therefore capped at 80 in our recreations and marked `[verify]`.
- Where sources A and S give different names for one slot, the DOS name from source A is used.

## Our recreations and their simplifications

Our levels keep the puzzle idea and the numbers above where they are known. Where our simulation
behaves differently from the original, or a value is `[verify]`, the level is simplified. Every
simplification is listed here.

| Level | Simplification |
| --- | --- |
| all | Skill counts are ours; the text sources do not give them. |
| all | Lemming counts above 80 are capped at 80 (vision G-15). |
| Fun 3 | Water below the ledge ends replaces the original's deadly drops, so that each of the three blockers is needed. |
| Fun 5 | The wire mesh in front of the exit is two solid fence posts; our lemmings cannot walk up a mesh. |
| Fun 6 | Our explosion removes only 4 px below the feet, so the hatch floor is 4 px thin and the wall by the exit 5 px. |
| Fun 7 | Our builders do not stop walkers, so a few lemmings fall into the pit before the bridge is finished; the target (50 %) allows for it. |
| Fun 9 | The fire on the left is a pool; the pillar is thick enough that bashing alone saves too few, so a blocker is needed as in the walkthrough's fallback. |
| Fun 10 | The floater of the original is optional here: the first lemming out of the miner's tunnel can become the blocker. |
